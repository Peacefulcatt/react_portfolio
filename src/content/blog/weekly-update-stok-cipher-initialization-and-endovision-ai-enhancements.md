## Stok_Cipher Repository Setup
Work began on the **Stok_Cipher** project with the initialization of the repository. A README, agent notes, and make targets were added to the repository root. These additions allow the entire stack to be run and explained directly from the repo.

## EndoVision-Ai Interface Improvements
The **EndoVision-Ai** project received several UI updates. Keyboard navigation was implemented, along with a toggle to display shortcuts. An in-menu about page was also introduced, featuring version 2.0.0 and the project logo.

## EndoVision-Ai Performance and Bug Fixes
An ONNX speed benchmark was integrated into the project. Following this, a fix was applied to the UI to reset the mode to 'none' when switching videos. This change also adapted the AI playback speed to function correctly in the new context.
