## CNC_Freedom: Enhanced Job Setup and Operations

This week, we made significant progress on CNC_Freedom. The FreeCAD shop panel now supports datum selection, shared job mesh, and leftover stock visualization for 3-axis jobs. We added mesh cavity roughing, which reuses a FreeCAD OCL process to streamline roughing operations without restarting FreeCAD. Native 3D shop operations were introduced, allowing the kılıf setup to post without relying on FreeCAD Path. Additionally, the 2.5D shop dock was completed and labeled with Turkish NX terms, improving usability for Turkish-speaking users.

## DWG-DXF-to-PDF-Converter: Initial Release

We also launched a new project: a DWG/DXF to PDF converter. The initial commit includes a graphical user interface and packaging, providing a straightforward way to convert CAD files to PDF format. This tool aims to simplify file sharing and documentation workflows.
