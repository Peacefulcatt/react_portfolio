## Startup Model Check for Mouse Input

This week, we added a startup model check for mouse input in EndoVision-Ai. This feature ensures that the model is verified at startup when mouse input is used, improving initialization reliability.

## Label and Score Display Toggles in Inference

We also introduced support for toggling label and score displays across different modes during inference. This allows users to customize the visibility of labels and scores based on their preferences.
