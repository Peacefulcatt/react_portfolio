# Umut Yıldız Portfolio

Personal portfolio rebuilt with [Astro](https://astro.build).

## Pages

- Home
- About
- Projects
- Blog (Markdown content collection)
- Contact

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deploy

GitHub Pages deploy uses the project base path `/react_portfolio`:

```bash
npm run deploy
```
